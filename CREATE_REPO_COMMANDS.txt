Troubleshooting
═══════════════════════════════════════════════════════════════════════

If "remote origin already exists":
    git remote remove origin
    git remote add origin https://github.com/mribeirodantas/nf-codespaces.git

If authentication fails (HTTPS):
    Use Personal Access Token as password
    Generate at: https://github.com/settings/tokens

If SSH authentication fails:
    Check SSH key: ssh -T git@github.com
    Add key at: https://github.com/settings/keys

To check current status:
    cd /home/user/nf-codespaces
    git status
    git log --oneline
    git remote -v
